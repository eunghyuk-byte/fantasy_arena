> 모델: HS 바닐라 몸체 앵커 + **점진 DEF 가중**(1st 2.5 / 2nd 3.0 / 3rd 3.5) + 코인 EV(+ / −).

## 핵심 공식 (짧게)

```
공체합 = 공 + 체                              # DEF=0이면 ≈ 2C+1 (HS)
가중점수 = 공 + 체 + W(DEF)                   # 점진 누적 가중
W(0)=0, W(1)=2.5, W(2)=5.5, W(3)=9.0         # 한계: +2.5 / +3.0 / +3.5
목표 가중점수 ∈ [2C+1 , 2C+4]                  # 바닐라 몸체 밴드
DEF ≥ 0 · |defC| ≤ DEF · DEF ≤ 3          # 방 바닥·방코인≤방·하드캡
```

| 규칙 | 내용 |
|------|------|
| DEF 가치 | 매 타격 감쇠·마모 없음 → **한계 가중 점진**: 1방=+2.5, 2방=+3.0, 3방=+3.5 |
| 누적 W | DEF1→**+2.5**, DEF2→**+5.5**, DEF3→**+9.0** (`가중점수`에 가산) |
| DEF=0 | `공체합 ≈ 2C+1` (HS 바닐라) |
| DEF>0 | 방 추가 시 공체를 `한계 가중`만큼 희생해 `가중점수` 밴드 유지 |
| 방캡 | **전 코스트 ≤3** (바닐라·전설·물 포함. 4·5 금지) |
| 코인 | 플러스 EV≈+0.5 / 마이너스 EV≈−0.5 / ±스윙 EV≈0 → 몸체와 교환 |
| 스킬 | 특수공격은 기준 몸체에서 **세금 차감 후** 편성 |

## 표2 코인 RULES

### 카드별 총량·배분

- 카드 한 장의 코인 총합은 **최대 5개**다. 플러스·마이너스(± 포함)를 합산한다.
- `N_coin = N₊ + N₋ + N± ≤ 5` (공·방·체에 배분된 각 코인 수의 합).
- 코인 수는 코스트에 묶이지 않는다. 2코스트에도 **플러스 ATK 코인 5개**를 둘 수 있다.
- 5개 이내에서 공·방·체 배분은 자유다.
- `DEF ≥ 0`, `DEF ≤ 3`, 방코인은 항상 **`|defC| ≤ DEF`**.

### + / − 코인 판정과 EV

| 종류 | heads | tails | EV | 밸런스 메모 |
|------|-------|-------|-----|-------------|
| **플러스 (+)** | **+1** | **0** | **+0.5/개** | 기대값만큼 몸체 세금 적용 |
| **마이너스 (−)** | **0** | **−1** | **−0.5/개** | 위험 보상으로 몸체 상향 가능 |
| **±스윙** | **+1** | **−1** | **≈0** | 평균은 중립, 변동성은 별도 평가 |

> 마이너스 = “앞면 변화 없음 / 뒷면 −1”. (±스윙과 혼동 금지.)

### 기대 점수·밸런스 메모

```
기대가중점수 = 가중점수
             + 0.5×(공코인₊ + 체코인₊ + Σ w_marginal(방코인₊))
             − 0.5×(공코인₋ + 체코인₋ + Σ w_marginal(방코인₋))
```

방코인 한계 가중 `w_marginal` (현재 DEF 기준, 적용 순서로):

| 다음 DEF 점 | w_marginal |
|--:|----------:|
| 0 → 1 | **2.5** |
| 1 → 2 | **3.0** |
| 2 → 3 | **3.5** |

- ±스윙은 기대값 `≈0`으로 계산하되, 변동성과 체감 위험을 별도 검토한다.
- 방코인은 `가중점수`에서 **점진 한계 가중**이 붙으므로 같은 수의 공·체 코인보다 비싸다 (특히 2·3번째 방).
- `기대가중점수`가 목표 밴드 상단+3 이상이면 코인을 줄이거나 몸체를 −1 한다.
- 코스트별 코인 할당량은 없다. 카드당 최대 5개를 공·방·체에 자유 배분한다.

### 코인 ↔ 몸체 세금

| 규칙 | 내용 |
|------|------|
| 플러스 | 기대 스탯 +1당 몸체(공체) ≈ **0.5** 삭감 (`N`개 → 세금 ≈ `0.25N`) |
| DEF 코인 | `w_marginal×0.5`로 기대가중점수 진입 → **더 비쌈**(고차 DEF일수록) |
| 마이너스 / ± | EV≤0 → **몸체 상향(위험 보상)** 이 기본 (플러스 세금과 반대) |
| 밴드 | 몸체 `가중점수` 우선. `기대가중점수`가 상단+3 이상이면 코인↓ 또는 몸체 −1 |

## 표3 특수공격 가중치(세금)

적용 순서: **① 스킬 세금 → ② 종족 편차 → ③ 코인 풀·EV**.  
세금 = 표1 바닐라 대비 몸체/`가중점수` 차감.

| 스킬 | 가중점수 세금 또는 공 삭감 | 비고 |
|------|-------------------|------|
| **일반** | **0** | 바닐라 기준선 |
| **관통** | **−1** (ATK−1 또는 HP−1) | 방 풀 선소모·잔여→HP |
| **돌진** | **−1** (~DEF↓ 시 −1~−4) | 피해에 공격자 DEF 가산 |
| **연속** | **−2 ~ −3** (**ATK−2** 권장, HP 유지) | **hit→반격→hit→반격** (2히트+반격2). ×2 침묵 모델 금지 |
| **치명** | **−3 ~ −4** (ATK−2~−3 **그리고** HP−1) | HP1만 들어가도 즉사 → 중과세 |
| **흡혈** | **−1** (ATK−1 또는 HP−1) | 준 HP 피해 절반(올림) 회복 · 풀피 초과 불가 |
| **약화** | **−1** (ATK−1) | 선제 대상 공−1·방−1 후 타격 |
| **석화** | **−1 ~ −2** (ATK−1 · DEF↓ 가능) | 선제 대상 공=0·방+1 후 타격 |
| **광역** | **ATK → 1~2 고정** | 적 전체 · 대상별 DEF · `atk≤def→HP0`. 추가 과세 과함 |
| **돌파** | **−1** (ATK−1 또는 HP−1) | 처치 시 잔여 ATK 트램플(홉마다 DEF 재적용) |
| **혼란** *(예정)* | **−2 ~ −3** (ATK−2 또는 HP−2) | **반격 없음** · 안전 화력 → 연속과 세금 비슷~이상. **미구현** |

**연속(CRITICAL):**  
`hit1 → (생존 시) counter1 → hit2 → (생존 시) counter2`. 반격은 스킬 없는 일반 타격. HP 우선 보존.

**연속 vs 혼란:** 연속=고화력+이중 반격 / 혼란=화력+반격 면역 → 혼란이 보통 더 비싼 키워드.

## 속성 편차 한 줄씩

| 속성 | 한 줄 |
|------|--------|
| 🪨 **땅** | HP +1~+2 · 체+코인 · ATK−1 및/또는 DEF−1 |
| 🔥 **불** | ATK +1~+3 · **헤비 마이너스**(0/−1) · HP−1~−2 · DEF 0~↓ |
| 💧 **물** | DEF +1(≤**3**) · 방+코인 · ATK/HP 희생 · 가중점수 세금 큼 |
| 🌬️ **바람** | ATK≈HP · DEF 낮게 · 코인 ±0~1 · 스윙 금지 |
| ✨ **빛** | 전 스탯 −1~−2 · **플러스만** · 저베이스=코인 세금 선반영 |
| 🌑 **암흑** | 전 스탯 +1~+2 · **±스윙**(+1/−1, EV≈0) · 고베이스=고위험 |

물 DEF도 하드캡 3. 방 +1 = 한계 가중(2.5/3.0/3.5)만큼 공체 희생 → 물은 공체 희생이 기본.

## 빠른 검산 (7줄)

1. `DEF ≤ 방캡` 이고 `DEF ≤ 3`?
2. `|defC| ≤ DEF` · `DEF ≥ 0`?
3. DEF=0 → `공체합≈2C+1`? DEF>0 → 공체 희생 ≈ `W(DEF)` (2.5 / 5.5 / 9.0)?
4. 몸체 `가중점수`가 코스트 밴드(±종족/스킬) 안?
5. 코인 총합 ≤ 5개·공/방/체 자유 배분? 종족 규칙(불=−, 빛=+, 바람±1, 암흑±) OK?
6. `기대가중점수` 과도하면 코인/몸체 세금 적용?
7. 스킬 있으면 표3 · 연속은 **hit→반격→hit→반격**?
