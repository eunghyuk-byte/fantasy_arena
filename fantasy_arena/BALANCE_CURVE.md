## 3. 공유 코인 (런타임 필수)

- 물리 코인 **N개(1~5)** 만 **한 번** 돌린다. 공/방/체 코인을 따로 돌리지 않는다.
- 카드 필드: 각 스탯에 `+N` / `−N` / `0` (비0이면 `|값| === N` 필수).
- 앞면 수 **H** → 연결된 스탯이 **동시에** `±H` (해당 스탯의 부호).
- 예: `N=5`, 공+, 체− → 앞면 5면 공+5·체−5 / 뒷면 5면 둘 다 0.
- UI도 코인 N개만 **한 세트**로 플립 연출한다.

### 데이터 포맷 (마이그레이션 규칙)

```text
N = max(|atkC|, |defC|, |hpC|)
atkC = sign(atkC)*N  if atkC≠0 else 0   (defC/hpC 동일)
전부 0인 유닛 → N=1, atkC=+1 강제 (유닛 코인 0 금지)
```

**삼국지(SGZ) id 카드는 마이그레이션하지 않음** (e21–e44, f21–f25, n21–n25, a21–a25, l21–l25, d21–d25 등).

### 코인 점수 (문서용 CM)

공유 풀 N에 링크된 스탯마다 위험 조정 크레딧을 적용한다 (같은 N을 링크 수만큼 반영).

| 유형 | 개당 | 비고 |
|---|---:|---|
| +공 / +체 | **+0.4** | 수학 EV +0.5에서 위험 0.1 차감 |
| −공 / −체 | **−0.6** | 수학 EV −0.5에서 손실회피 0.1 가산 |
| +방 | **+0.4 × (다음 방 마진)** | 마진 2.0/2.5/3.0/3.5/4.0 |
| −방 | **−0.6 × (잃는 방 마진)** | 동일 마진 스케일 |
| ±스윙(같은 풀에 +/− 혼재) | ≈0 + 변동성 | 기댓값 상쇄, 체감 위험 별도 |

`N ≤ 5`. 유닛 `N ≥ 1`.

## 4. 속성 코인 필수 (제작 필터 — 런타임 강제 아님)

| 속성 | 규칙 |
|---|---|
| 땅 | **체 코인 필수** (링크) |
| 불 | **공 코인 필수** |
| 물 | **방 코인 필수** |
| 바람 | **N ≤ 2** |
| 빛 | **전부 +** (마이너스 링크 금지) |
| 암 | **N = 3~5** 이고 **+/− 맞교환** (같은 풀에 플러스·마이너스 링크 공존) |

기존 카드 전면 재작성 금지. 신규/리밸런스 시에만 적용.

## 5. 바닥·캡 (런타임 필수)

코인 적용 후:

- **체 ≥ 1**
- **공 ≥ 0**
- **방 ≥ 0 그리고 방 ≤ 5** (클램프)

제작 시 추가:

- `|체−| ≤ 기본체−1`
- `|공−| ≤ 기본공`
- `|방−| ≤ 기본방`
- 방+ 링크면 `N ≤ (5 − 기본방)`

## 6. 특능 (런타임 + 라벨/DESC/도움말)

**반격 공통:** `혼란(11)`을 제외한 모든 공격은 대상 생존 시 반격.  
**연속(4):** `1타→반격→2타→반격` (데미지 ×2 아님).  
**광역(9):** 반격은 맨 앞(첫) 대상만.  
**돌파(10):** 처치 후 **남은 공격력(오버킬 잔여)** 만 다음 대상.

| id | 이름 | 효과 | 비용 |
|---:|---|---|---:|
| 1 | 일반공격 | 공만큼 피해 | **0** |
| 2 | 관통공격 | 먼저 방 깎고 남는 피해→체 | **1.0** |
| 3 | 돌진공격 | 내 방만큼 추가 피해 | **2.5** |
| 4 | 연속공격 | **두 번 공격** (1타→반격→2타→반격). ×2 아님 | **3.25** |
| 5 | 치명공격 | 체 1이라도 깎이면 즉사 (공1~3) | **4.0** |
| 6 | 흡혈공격 | 준 체 데미지 절반(올림) 회복 | **1.5** |
| 7 | 약화공격 | 타격 전 대상 공/방 −1 | **1.0** |
| 8 | 석화공격 | 타격 전 대상 공=0·방+1 | **2.75** |
| 9 | 광역공격 | 적 하수인 전체(대상별 방). 반격=맨 앞만 | **4.5** |
| 10 | 돌파공격 | 처치 후 **남은 공격력**만 다음 | **1.25** |
| 11 | 혼란공격 | 타격. **반격 없음** | **1.5** |

### 특능 자격 (제작 게이트)

- **돌진(3):** 기본 방 ≥ 2 (예외: 기본 방 1 + 방+ 코인으로 실전 방 ≥ 2). 기본 방 0 금지. −방 코인 금지.
- **돌파(10):** 기본 공 ≥ 5 (예외: +공 헤비로 실전 공 ≈ 5). 저공 돌파 금지.
- **연속(4):** 기본 공 ≥ 3.
- **치명(5):** 기본 공 1~3. 고공 치명 금지.
- **흡혈(6):** 기본 체 ≥ 5. 방 ≈ 0 원칙.
- **약화(7) / 석화(8):** 기본 공 ≥ 1.
- **광역(9):** 기본 공 1~4 (공 ≥ 5 금지). 공 3~4는 의도적 고비용.
- **혼란(11):** 저체·고공 조합 허용.
