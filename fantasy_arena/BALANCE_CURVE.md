# Fantasy Arena · 코스트 커브 공식 (FORMULA ONLY)

> 작성·개정: 2026-09-20 (KST) · **승인 전 공식 문서**  
> 카드 수치·`cards-data.js` / 게임 코드 **수정 금지**. 승인 후 별도 리밸런스.  
> 기준: HS 바닐라 몸체 앵커 + **점진 DEF 가중**(2.5 / 3.0 / 3.5) + 코인 EV.

## 핵심 공식

```text
공체합 = 공 + 체
가중점수 = 공 + 체 + W(방)
W(0)=0, W(1)=2.5, W(2)=5.5, W(3)=9.0
방의 한계 가중 = 0→1: 2.5, 1→2: 3.0, 2→3: 3.5
목표 가중점수 ∈ [2C+1, 2C+4]
방 ≥ 0 · |방코인| ≤ 방 · 방 ≤ 3
```

아래 세 표가 카드 설계 시 우선 적용하는 공식 표다. 특능 세금과 코인 점수는 표1의 기준 가중점수에서 계산한다.

## 표2 「표: 특능 가중점수」

**특능이 있으면 표1의 기준 가중점수에서 가중(세금)점수만큼 차감한다.** `공 강제`가 적힌 행은 세금 차감 대신 해당 공격 수치를 강제하고, 둘을 중복 적용하지 않는다.

| 특능 | 가중(세금)점수 | 비고 |
|---|---:|---|
| **일반** | **0** | 기준선, 특능 없음 |
| **관통** | **−1.0** | 방 풀을 먼저 소모하고 잔여 피해를 체로 보냄 |
| **돌진** | **−2.5** | 피해에 공격자 방을 가산하는 DEF1 수준의 추가 효율 |
| **연속** | **−3.0 ~ −3.5** | **hit→counter→hit→counter**; 반격은 일반 타격 |
| **치명** | **−3.5 ~ −5.5** | HP 1만 남아도 즉사하는 효과라 중과세 |
| **흡혈** | **−1.0** | 준 HP 피해 절반(올림) 회복, **풀피 초과 불가** |
| **약화** | **−1.0** | 선제 대상 공−1·방−1 후 타격 |
| **석화** | **−2.5 ~ −3.0** | 선제 대상 공=0·방+1 후 타격 |
| **광역** | **−2.5** 또는 **공 1~2 강제** | 적 전체, 대상별 방 적용; 공≤방이면 체 0 |
| **돌파** | **−2.5** | 처치 시 **남은 공**으로 트램플, 매 홉 방 재적용 |
| **혼란예정** | **−3.5 ~ −5.5** | **반격 없음**; 안전 화력, 미구현 |

세금은 특능의 기대 효율을 공체에서 먼저 깎는 값이다. 예를 들어 `−2.5`는 기준 가중점수에서 2.5를 빼거나, 같은 효과가 되도록 공/체를 줄인다는 뜻이다. 광역은 `공 1~2 강제`를 선택한 경우에만 강제식을 적용한다.

## 표3 코인 점수표

코인 1개는 앞면에서 +1, 뒷면에서 0인 **플러스(+)** 코인 기준이다. 공·체 코인은 가중점수에 +0.5 EV만 더하지만, 방 코인은 다음 방의 점진 가중을 타므로 더 비싸다.

| 코인 유형 | 1개 | 2개 | 3개 | 4개 | 5개 | 산식 / 적용 |
|---|---:|---:|---:|---:|---:|---|
| **+공** | +0.5 | +1.0 | **+1.5** | +2.0 | +2.5 | `+0.5 × 개수` |
| **+체** | +0.5 | +1.0 | **+1.5** | +2.0 | +2.5 | `+0.5 × 개수` |
| **+방 (다음 0→1)** | +1.25 | +2.50 | **+3.75** | +5.00 | +6.25 | `+0.5 × 2.5 × 개수` |
| **+방 (다음 1→2)** | +1.50 | +3.00 | **+4.50** | +6.00 | +7.50 | `+0.5 × 3.0 × 개수` |
| **+방 (다음 2→3)** | +1.75 | +3.50 | **+5.25** | +7.00 | +8.75 | `+0.5 × 3.5 × 개수` |
| **−공 또는 −체** | −0.5 | −1.0 | **−1.5** | −2.0 | −2.5 | `−0.5 × 개수` |
| **−방 (1→0 손실)** | −1.25 | −2.50 | **−3.75** | −5.00 | −6.25 | `−0.5 × 2.5 × 개수` |
| **−방 (2→1 손실)** | −1.50 | −3.00 | **−4.50** | −6.00 | −7.50 | `−0.5 × 3.0 × 개수` |
| **−방 (3→2 손실)** | −1.75 | −3.50 | **−5.25** | −7.00 | −8.75 | `−0.5 × 3.5 × 개수` |
| **±스윙** | ≈0 | ≈0 | ≈0 | ≈0 | ≈0 | 기대값 0, 변동성은 별도 평가 |

- **예시:** 플러스 코인 3개는 `+공` 또는 `+체`면 **+1.5점**이다. 다음 방이 1→2라면 `+방` 3개는 **+4.5점**으로, 공/체 3개보다 훨씬 비싸다.
- 방 코인 표의 값은 해당 코인이 같은 다음 방 한계에 적용되는 기대값이다. 방이 올라가 한계가 바뀌면 2.5→3.0→3.5를 순서대로 다시 적용하고, 방 하드캡 3에서 멈춘다.
- 마이너스(−)는 앞면 변화 없음·뒷면 −1이라 음의 EV다. ±스윙은 평균 ≈0이지만 변동성과 체감 위험을 별도로 본다.
- 카드 한 장의 코인 총량은 **최대 5개**이며, 공·방·체에 **자유 배분**한다: `N_coin=N₊+N₋+N±≤5`.
- 방 코인은 항상 `|방코인|≤방`, `방≥0`, `방≤3`을 지킨다. 방 코인은 공/체 코인과 같은 값으로 환산하지 않는다.

### 코인 기대 가중점수 공식

```text
기대 가중점수 = 기준 가중점수
  + 0.5×(+공 개수 + +체 개수)
  + 0.5×(2.5/3.0/3.5)×(+방 개수)
  − 0.5×(−공 개수 + −체 개수)
  − 0.5×(2.5/3.0/3.5)×(−방 개수)
```

`2.5/3.0/3.5`는 코인이 붙는 **다음 방 점**을 뜻한다. 코인 후 기대 가중점수가 코스트 밴드 상단+3을 넘으면 코인 또는 몸체를 줄인다.

## 속성 편차 공식

| 속성 | 원칙 |
|---|---|
| 🪨 **땅** | 체 +1~+2, 공−1 및/또는 방−1 |
| 🔥 **불** | 공 +1~+3, 헤비 마이너스(0/−1), 체−1~−2, 방 0~↓ |
| 💧 **물** | 방 +1(최대 3), 방 코인 사용 시 공/체 희생 |
| 🌬️ **바람** | 공≈체, 방 낮게, 코인 ±0~1 |
| ✨ **빛** | 전 스탯 −1~−2, 플러스 코인만 |
| 🌑 **암흑** | 전 스탯 +1~+2, ±스윙(+1/−1, EV≈0) |
