설정

플레이 방식

같은 화면에서 둘이 번갈아 하는 모드입니다.

해상도

하스스톤처럼 고정 4:3 게임 창 크기를 고릅니다. 창이 더 크면 검은 여백(레터박스), 작으면 비율을 유지한 채 축소됩니다.

도움말

기본 규칙

영웅 체력 40. 덱 30장.
피해는 (공격−방어)만큼, 최소 0.
공격·방어는 0 아래로 안 내려갑니다. 체력이 0 이하면 죽음.
전장 유닛은 최대 5장.
턴 종료 시 왼쪽부터 자동 공격. 상대 유닛이 없으면 영웅을 공격합니다.
상대가 살아 있으면 반격합니다.

코인

코인을 한 번만 돌립니다. 골드 코인(앞면)=스탯 상승, 블랙 코인(뒷면)=스탯 하락.

카드 등급

  • 커먼 — 기본 등급. 같은 카드 최대 2장.
  • 언커먼 — 커먼보다 희소. 같은 카드 최대 2장.
  • 레어 — 고등급. 덱에 1장만.
  • 레전드 — 최고 등급. 덱에 1장만.

특수공격

  • 일반공격 — 공격력만큼 공격합니다.
  • 관통공격 — 방어를 깎고, 남은 피해가 체력으로 갑니다.
  • 돌진공격 — 내 방어력만큼 더 공격합니다.
  • 연속공격 — 두 번 공격합니다.
  • 치명공격 — 체력이 1 이상 깎이면 바로 죽습니다.
  • 흡혈공격 — 준 피해의 절반만큼 체력을 회복합니다.
  • 약화공격 — 먼저 상대 공격·방어를 1씩 낮춥니다.
  • 석화공격 — 먼저 상대 공격을 0으로, 방어를 +1 합니다.
  • 광역공격 — 적 유닛을 전부 공격합니다.
  • 돌파공격 — 죽인 뒤 남은 공격력으로 다음 적을 공격합니다.
  • 혼란공격 — 공격하지만, 상대가 반격하지 않습니다.

특수능력

  • 보호 — 피해를 한 번만 막아 줍니다. (코인으로 체력이 깎일 때는 안 막힘)
  • 복수 — 나를 죽인 적 유닛도 같이 죽습니다.
  • 환생 — 죽으면 체력 1로 한 번 다시 살아납니다.
  • 강탈 — 나를 죽인 적을 내 편으로 가져옵니다.
  • 출전 — 낼 때 드로우1
  • 유언 — 죽을 때 드로우1
  • 면역 — 스펠 효과를 받지 않습니다.

종족

  • 인간 — 병사·기사·드워프·오크 같은 사람형.
  • 정령 — 요정·술사·속성 정령.
  • 짐승 — 동물·몬스터.
  • 용족 — 드래곤·와이번·피닉스.
  • 거인 — 거인·거대 존재.
  • 골렘 — 돌·마법으로 움직이는 구조물.
  • 언데드 — 해골·유령·리치 등.
  • 악마 — 악마·지옥 계열.
  • 벌레 — 현재 미사용 (카드 없음).
  • 무장 — 삼국 등 이름 있는 장수.
  • 토큰 — 스펠 등으로 소환된 유닛. 배너에 「토큰」.
