## 3. 공유 코인 (런타임 필수)
- 물리 코인 N개(1~5)만 **한 번** 돌림. 공/방/체 코인 따로 돌리지 않음.
- 카드 필드: 각 스탯에 +N/−N/0 (비0이면 |값|===N 필수)
- 앞면 수 H → 연결된 스탯이 동시에 ±H
- 예: N=5, 공+, 체− → 앞면5면 공+5·체−5 / 뒷면5면 둘 다 0
- UI도 코인 N개만 한 세트로 플립 연출

데이터 마이그레이션(기존 atkC/defC/hpC):
- N = max(|atkC|,|defC|,|hpC|) (최소 1이면 유지; 전부0이면 유닛은 코인1 이상 강제하되 이번엔 기존 0코인 유닛이 있으면 N=1 공+ 등으로 최소 보정하거나 기존 의도 유지—유닛 코인0 금지 룰이므로 |값이 모두0|인 유닛은 coinN=1 공+ 부여)
- 각 스탯 sign 유지, 절댓값은 N으로 통일: atkC=sign(atkC)*N if atkC!=0 else 0 (동 defC/hpC)
- **삼국지(SGZ) id 카드는 마이그레이션하지 말고 현행 유지** (나중에 일괄)

## 4. 속성 코인 필수 (제작 필터 — 런타임 강제 선택)
땅=체 필수 / 불=공 필수 / 물=방 필수 / 바람 N≤2 / 빛 전부+ / 암 N=3~5 +/−맞교환
문서에만 명시. 기존 카드 전면 재작성 금지.

## 5. 바닥·캡 (런타임 필수)
코인 적용 후:
- 체 ≥ 1
- 공 ≥ 0
- 방 ≥ 0 그리고 방 ≤ 5 (클램프)
제작 시: |체−|≤기본체−1, |공−|≤기본공, |방−|≤기본방(블랙만; 방0이면 방− 금지).
방+(골드)는 기본방 0에도 가능. 방+면 N≤(5−기본방)로 코인 후 방≤5 맞춤. (2026-09-22 명확화)

## 20. 코인 개수 ± (공유 N) (2026-09-21)
- 「코인+1/−2」는 골드/블랙 변환이 아니라 **공유 물리 코인 N**만 증감.
- 링크 부호 유지, 비0 링크는 |값|=newN. N=0이면 전 링크 0.
