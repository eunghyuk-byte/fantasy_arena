# 카드아트 용량 락 (2026-09-23 / v0.205)

## 배포 스펙 (저장소에 들어가는 최종본)
- 해상도: **1000×800**
- 포맷: JPG
- quality: **90**
- 목표: 카드 천장(1000장+)에서도 `/art` 합계 **약 300MB 안쪽**

## 신규 카드 운영 (사용자 지정 2026-09-23)
- E23 등 **생성은 기존처럼 1500×1200 고퀄로 받아도 됨**
- 게임에 넣기 전(또는 넣은 직후) **반드시 이 스펙으로 일괄 변환**
- 신규 아트가 추가되면 PM/담당이 **「art 1000×800 Q90 변환 필요」** 를 알려 변환 돌릴 것
- 생성 프롬프트를 처음부터 1000×800으로 바꾸지 않음 (생성 품질 유지 → 변환으로 맞춤)

## 변환 커맨드 예
```bash
convert IN.jpg -resize '1000x800!' -strip -interlace Plane -quality 90 OUT.jpg
```
